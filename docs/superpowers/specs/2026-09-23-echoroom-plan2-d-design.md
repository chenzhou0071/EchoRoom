# EchoRoom 计划2 · D 子项目设计：设置系统

**日期**：2026-09-23
**状态**：设计已确认（brainstorming 完成，逐节获批）
**前置**：A（UI 改版 + 个体音量）、B（视频子系统）、C（账号系统）已完成
**上位文档**：`2026-09-18-echoroom-plan2-overview.md`（本文件是其子项目 D 的细化）

## 背景与目标

计划2 的收官子项目：集中化设置入口，提供账号资料、音频设备、进出音效、主题外观四类设置；并将 C 阶段明确划来的"改资料入口、登出入口"落地。

**本轮 brainstorming 确认的需求基线**：

- **入口**：顶栏行加高、标题 Echo 放大；顶栏右侧（连接状态右侧）加 ⚙ 按钮；登录后才可用（登录页显示期间不可开）
- **设置页形态**：点击 ⚙ 后**覆盖"顶栏以下整个窗口"**；左列（顶部 `‹ 返回`、分类列表、底部版本号），右侧内容区；返回后主界面状态无损（覆盖式显示，不销毁主界面）
- **4 个分类**：账号 / 设备 / 音效 / 外观
- **账号**：头像预览 + 昵称 + 账号名（只读）+ [修改资料] + [退出登录]（两段式确认）
- **设备**：麦克风/扬声器/摄像头三组下拉；首项固定「系统默认」；**选择后立即生效**（热切换）；失效自动回退并提示；进页面/展开下拉时重新枚举
- **音效**：块状列表，每块 = 一套音效（入场 + 离场）；**点块 = 选中使用**（单选，● 使用中标记）；每块两个**试听按钮**（入场/离场，试听不影响选中）；含「关闭（无提示音）」块；新增音效 = 放目录 + 注册表加一行
- **外观**：6 套成套主题（点选立即应用）；自定义背景图（选择/清除），**铺满侧栏 + 成员卡片区 + 聊天区**
- **主题含义**（用户确认）：底色系（窗口/面板/边框）+ 强调色（发送按钮、说话框、聚焦边、链接、激活态）**成套切换**；文字色与语义色（成功绿/错误红）不变；说话框随强调色（现状已是）
- **后台不暂停**：设置页打开期间，成员进出/聊天/语音照常
- **版本号**：显示在设置页左列底部（形式 `v0.3.0`）

## 范围

**包含**：顶栏改造 + 设置页（4 分类）全部 UI；主题系统（6 套 + CSS 变量组）；背景图（选择/清除/持久化/铺层）；音频输入/输出设备枚举与热切换；摄像头设备选择；进出音效方案选择（Default / 关闭 / 可扩展接口）；修改资料入口（复用既有弹窗）；退出登录；客户端版本 0.3.0。

**不包含**（明确划出）：

- 投屏设置收纳进设置页（维持投屏预览视图的浮动面板）
- 提示音音量调节（保持固定 0.5）
- 麦克风试音电平条
- 登出通知服务器（客户端断开 + 清本地凭证即可；服务器 token 24h 滑动过期自然失效）
- 主题自定义取色（仅 6 套预设）；背景图模糊/亮度调节（固定半透明罩）
- 服务器地址展示/修改（登录页已有，登出后可改）

- 头像预览复用现有头像缓存渲染；昵称/账号来自服务器成员信息
- [修改资料] → 打开现有资料弹窗（`profile-mask`），标题统一改为「个人资料」（注册后首弹语义兼容）
- [退出登录] → 两段式确认（点一次按钮变为"确认退出？"，再点执行；3 秒未动自动恢复）→ 清 `auth_token` → 断开连接（复用现有断线清理：音频管线/视频会话）→ 回登录页；`account` 保留预填

### 2.2 设备

```
设备
┌──────────────────────────────┐
│  麦克风   [ 系统默认         ▾ ] │
│  扬声器   [ 系统默认         ▾ ] │
│  摄像头   [ 系统默认         ▾ ] │
└──────────────────────────────┘
```

- 每组下拉首项固定「系统默认」= 未指定时的现状行为
- **立即生效（热切换）**：
  - 麦克风/扬声器：Rust 音频线程内部软切换（详见 4.1），语音不断
  - 摄像头：正在使用时自动重启采集流（短暂中断）；未使用则下次开启生效
- **设备枚举**：麦克风/扬声器走 wasapi（Rust）；摄像头走浏览器 `enumerateDevices`（前端直接支持）
- **刷新**：进入设备页或展开下拉时重新枚举（免手动刷新）
- **失效回退**：所选设备不可用（拔出等）→ 自动回退「系统默认」+ 设置页内联提示一次
- 摄像头 deviceId 持久性依赖 WebView 存储（实现时验证；若不稳定，降级为每次启动重置「系统默认」）

## 3. 关键决策记录

| 决策 | 结论 | 理由 |
|------|------|------|
| 设置页形态 | 覆盖式全窗口页（非弹窗/抽屉） | 用户设定：4 类内容空间充足；主界面状态天然保留 |
| 分类数 | 4 类（账号/设备/音效/外观） | 音效从"设备"独立（用户要求单独列出） |
| 主题实现 | CSS 变量组 + `:root[data-theme]` | 现有 `:root` 变量体系直接复用；主题定义集中；JS 只切属性 |
| 音频切换 | 线程内软切换（不重启管线、不重进房） | 语音不断、状态保留；重启管线会丢抖动缓冲 |
| 扬声器切换实现 | 播放线程外层重初始化循环 | fill 闭包状态（抖动缓冲/解码器）完整跨设备保留 |
| 设备偏好表示 | 空串 = 系统默认（config 沿用空串风格） | 兼容现状；serde default 兼容旧配置 |
| 音效扩展方式 | 目录约定 + 注册表一行 | 用户后续会补充音效；零架构改动 |
| 背景图存储 | 复制入数据目录，bytes→Blob 加载 | 原文件移动/删除不受影响；复用头像既有手法 |
| 摄像头设备 | 浏览器 enumerateDevices + deviceId | 前端直接支持，Rust 无涉 |
| 登出 | 客户端清凭证 + 断开；不通知服务器 | token 有 24h 滑动过期；无需协议改动 |
| 协议/服务器 | 零改动 | 纯客户端功能 |
| 版本 | workspace bump 0.2.0 → 0.3.0 | 功能新增；协议未破坏 |

## 4. 技术设计

### 4.1 音频设备热切换（Rust）

- **枚举**：wasapi 设备集合（Capture / Render）→ 每项 `{ id, name, is_default }`（is_default 与系统默认端点 id 比对）
- **`MicCapture::open` 改造**：接受 `Option<&str>` 设备 id；None → 默认设备；指定 id 不存在 → 返回错误（由上层回退）
- **采集线程**：每轮循环检查 `SharedAudio.input_device` 是否变化 → 变化则 drop 旧句柄、按新偏好重开（失败 → 回退默认 + 上报事件）
- **播放线程**：`run_player` 改为外层循环：`loop { init_render(当前偏好) → render_loop(检测偏好变化则主动退出) }`；重开设备前后**同一 fill 闭包**，抖动缓冲/解码器/屏幕音频队列状态完整保留；新设备失败 → 回退默认重试，再失败上报事件并继续用默认
- **共享偏好**：`SharedAudio` 增加 `input_device` / `output_device`（`Arc<Mutex<Option<String>>>`；None=系统默认，config 的空串在启动加载时转为 None）
- **事件**：新增 `audio_device_fallback`（方向 + 原因）→ 设置页内联提示
- **可测性**：偏好比较与回退决策抽成纯函数单测；硬件打开本身不做单测

### 4.2 音效架构

见 2.3；配置字段 `sound_pack: String`（默认 `"default"`，`"none"` = 关闭）

### 4.3 主题与背景图

- CSS：6 组 `:root[data-theme="<id>"] { --bg/--panel/--text/--border/--accent/--accent-soft ... }`；默认组为现状值
- **顺手改造**：将 CSS 中硬编码的派生色（如按钮激活态 `rgba(59,130,246,.15)`、`rgba(248,113,113,.15)`）改为变量（`--accent-soft` / `--err-soft`），此后加主题不再动样式
- 应用：JS 设 `document.documentElement.dataset.theme`（启动时尽早应用防闪烁）+ 存 `config.theme`
- 背景图（Rust）：`set_background(Option<String>)`——Some 复制文件（先删旧）+ 记扩展名；None 删除文件；`get_background() -> Option<(Vec<u8>, String)>`（bytes + mime）；config 存 `background_ext: String`（空 = 无）

### 4.4 退出登录

`logout` 命令：清 `config.auth_token` → 保存 → 停止音频管线 + 关闭视频会话（复用现有断线清理路径）→ 关 TCP 连接 → 发事件让前端切回登录页（`account` 保留预填）。房间内其他成员收到该成员 leave 广播（服务器现有行为）。

### 4.5 新命令与配置字段

**bridge 新命令（9 个）**：

| 命令 | 参数 | 返回/行为 |
|------|------|----------|
| `list_audio_devices` | — | `{ inputs: [{id,name,is_default}], outputs: [...] }` |
| `set_input_device` | `id: String`（空=系统默认） | 存 config + 更新共享偏好（音频线程自动热切） |
| `set_output_device` | `id: String`（空=系统默认） | 同上 |
| `set_camera_device` | `id: String`（空=系统默认） | 存 config（前端读取应用） |
| `set_theme` | `theme: String` | 存 config |
| `set_sound_pack` | `pack: String` | 存 config |
| `set_background` | `path: Option<String>` | 复制/删除文件 + 存 config |
| `get_background` | — | `Option<(bytes, mime)>` |
| `logout` | — | 清凭证 + 断开 + 回登录页 |

**config 新字段（6 个，均带 serde default 兼容旧配置）**：

```rust
#[serde(default)] pub input_device: String,    // 空 = 系统默认
#[serde(default)] pub output_device: String,   // 空 = 系统默认
#[serde(default)] pub camera_device: String,   // 空 = 系统默认
#[serde(default = "default_theme")] pub theme: String,          // "dianlan"
#[serde(default = "default_sound_pack")] pub sound_pack: String, // "default"
#[serde(default)] pub background_ext: String,  // 空 = 无背景图
```

## 5. 错误与边界

| 场景 | 行为 |
|------|------|
| 设备失效（拔出/禁用） | 启动/切换时找不到 → 回退「系统默认」+ 设置页内联提示一次 |
| 新输出设备打开失败 | 回退默认重试；再失败上报事件并继续默认（语音不中断） |
| 背景图超限（>10MB） | 前端拒绝并提示；Rust 侧兜底拒绝 |
| 背景文件丢失（手动删） | 启动加载失败 → 静默无背景 + 清 config 标记 |
| 音效文件缺失 | 播放静默忽略，不崩溃 |
| 设置页打开时断线/被踢 | 关闭设置页 → 回登录页（现有流程） |
| 未登录 | ⚙ 不可用（登录页期间隐藏） |
| 摄像头运行中切设备 | 自动重启采集流（短暂中断，不退出摄像头态） |

## 6. 测试与验收

**Rust 单测**：

- `config.rs`：新字段 round-trip；旧配置（无新字段）加载取默认；默认值正确
- 音频偏好回退决策纯函数（选设备 id 归一化、失效回退判定）

**前端语法**：`node --check app.js` / `video_capture.js`

**手工验收（双客户端）**：

1. 顶栏改造生效；⚙ 打开/`‹ 返回` 关闭；开合后主界面聊天/卡片状态无损
2. 6 套主题逐套点选：底色系 + 强调色全变；重启客户端后保持
3. 背景图：选择 → 立即铺满（侧栏+卡片+聊天）+ 可读；重启保留；换图 → 旧文件被删；清除 → 恢复纯色 + 文件被删；>10MB 被拒
4. 麦克风切换：对方实际听到声音来源变化；拔出所选设备 → 回退默认 + 提示
5. 扬声器切换：声音从新设备输出；切换瞬间语音不中断（仅一瞬静默）
6. 摄像头：切换后开启使用新设备；运行中切换 → 自动重启（对方短暂黑屏后恢复）
7. 音效：Default 试听入场/离场；选中后进/出房实际播放；选「关闭」后无音效
8. 退出登录：两段确认 → 回登录页；重启不自动登录；重新登录正常；房间内他人看到自己离开
9. 修改资料：设置页入口改昵称/头像 → 双客户端全局刷新
10. 版本号显示 v0.3.0

**构建**：全量 `cargo test` + `cargo tauri build`；客户端版本 0.3.0（protocol/server 零改动，服务器无需重部署）。
